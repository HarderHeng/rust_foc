# STM32G431 FOC Rust Project Design

**Date**: 2026-04-03
**Target**: STM32G431CB with custom board (PC6 LED)

## Overview

Create a Rust FOC motor control project using Embassy framework. Initial phase focuses on basic infrastructure: clock configuration, LED control, and UART shell.

## Hardware Configuration

| Component | Specification |
|-----------|---------------|
| MCU | STM32G431CB (LQFP48) |
| HSE | 8MHz external crystal |
| SYSCLK | 170MHz (via PLL) |
| LED | PC6 (GPIO output) |
| UART2 | PB3 (TX), PB4 (RX) at 921600 baud |

## Clock Configuration

```
HSE (8MHz) → PLL M=2 → 4MHz → PLL N=85 → 340MHz → PLL R=2 → 170MHz SYSCLK
```

- AHB: 170MHz
- APB1: 170MHz
- APB2: 170MHz

## Project Structure

```
src/
├── bin/main.rs       # Application entry point, Embassy executor
├── bsp/
│   ├── mod.rs        # BSP module exports
│   ├── board.rs      # Clock and power configuration
│   └── config.rs     # Board-specific constants
├── driver/
│   ├── mod.rs        # Driver module exports
│   ├── shell.rs      # embedded-cli shell implementation
│   └── led.rs        # LED driver (PC6)
├── hal/              # HAL traits (empty for now, future FOC)
└── lib.rs            # Crate root
```

## Dependencies

- `embassy-stm32` v0.6.0 - STM32 HAL with async support
- `embassy-executor` v0.10.0 - Async task executor
- `embassy-time` v0.5.1 - Time primitives
- `embedded-cli` - Shell interface (from funbiscuit repo)
- `defmt` + `defmt-rtt` - Logging
- `panic-probe` - Panic handler
- `static-cell` - Static initialization
- `ufmt` - Lightweight formatting

## Features

1. **Clock Init**: BSP layer configures HSE + PLL for 170MHz
2. **LED Control**: Driver wrapper for PC6 GPIO with on/off/toggle
3. **Shell**: embedded-cli on USART2 with commands:
   - `led on|off|toggle`
   - `hello [name]`
   - `version`
   - `clear`
   - `system info`

## Tasks

- `shell_task`: Process UART RX bytes, handle CLI commands
- `heartbeat_task`: Toggle LED every second (optional, for visual confirmation)

## Build Configuration

- Target: `thumbv7em-none-eabihf`
- Profile: Release with `opt-level = "z"`, `lto = "fat"`
- Probe-rs for flashing and debugging

## Success Criteria

1. LED blinks or responds to shell commands
2. Shell accepts commands at 921600 baud
3. Clock configured to 170MHz (verified via defmt logs)
4. Clean build with probe-rs flash successful
