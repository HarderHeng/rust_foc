## 独立控制模型的结果与限制

`foc/tests/control_dynamics.rs` 使用独立 f64 RL/PMSM 微分方程和 RK4 积分，从实际 SVPWM 三相 duty 重建桥输出，包含一整个控制周期的电压指令延迟；母线变化立即作用于保持中的 duty。测试覆盖：

- 名义参数及 R/L 偏差、正负 D/Q 阶跃与反转：10 ms 后电流矢量误差低于 3 mA。
- ±300、±1000 rad/s 电角速度，包含交叉耦合与反电势：20 ms 后误差低于 8 mA。
- 前馈在测试转速下减少启动累计误差，低于关闭前馈时的 60%。
- 电压饱和后的参考反转、母线跌落与恢复，验证可恢复性和限幅。
- 10 Hz 速度环、100 ms 平均测速与 0.8 A/s 电流斜坡，正负 300 RPM 和不同合成惯量。

**模型揭示的限制：**在惯量 `J=5e-5 kg·m²`、粘性摩擦 `3e-5 N·m·s/rad` 的轻负载模型中，当前默认速度控制有振荡，观察到约 20 RPM 的尾段瞬时误差，尚未量化峰峰值与周期；该用例只要求尾段误差小于 50 RPM，不能视为精密稳速。`J=2e-4` 和 `5e-4` 的模型尾段误差小于 3 RPM。惯量与摩擦均为合成条件，并非当前电机实测参数。

模型未包含 shunt 开关噪声、真实采样延迟、AS5600 内部滤波、死区或机械非线性。它验证算法行为、记录参数敏感性，不能替代硬件保护与稳定性验收。后续可离线比较速度环采样/滤波/增益候选；生产默认值应结合真实惯量、摩擦与延迟后确定。

## 尚存边界

- Park 角仍为采样保持。仅 400 µs、7 极对、3000 RPM 就对应最多约 50.4° 电角转动，另有 I2C 与 AS5600 内部延迟；高速闭环必须评估这条链路。`age_us` 只度量从 ANGLE 事务开始算起的年龄。
- 最大测速采样间隔取最大配置转速的半圈时间与 10 ms 的较小值；超过间隔即重建窗口。高于配置最高转速的多圈混叠不能由单圈绝对编码器消除。
- NVM 保持单页预留。半写追加可回退前一有效记录；满页擦除后掉电仍可能丢失全部校准，启动将要求重新对齐。双页原子存储需要重新分配 FLASH，当前未改布局。真实 flash ECC/欠压故障行为待测。
- flash 写入仍可能暂停取指；校准和满页回收必须适配 IWDG 最短实测期限。
- 双 ADC 等待、UDIS 成组提交与 down-count deadline 具有运行时拒绝路径；实际 JEOS 相位、功率级窗口及噪声需要示波器验收。

## 正式上板时的顺序

具体步骤见 [安全与上板验收](safety-bringup.md)。此前环境未检测到探针/USB/串口；本轮未重新枚举设备。

1. 确认板型、电源限流、调试器及 UART；记录 ELF 与 manifest。
2. 先到 Idle，检查默认门极输出、VBUS/NTC、AS5600 和故障状态。
3. 验证普通/注入 ADC 共存、双 ADC 完成异常、PWM 窗口与保护关断。
4. 测量完整 IRQ 延迟、寄存器提交期限、嵌套中断栈峰值及 IWDG 复位输出。
5. 验证 NVM 追加、满页回收和受控断电恢复。
6. 完成限流空载对齐，再做低电流电流环、低速正反转和轻惯量速度环评估。
7. 测量编码器到 PWM 的总延迟，再决定预测/滤波、PI 和性能优化候选。
8. 保存 Git revision、固件 SHA、命令、日志、波形与实测参数，更新验收结论。

上板操作在用户本轮“正式上板以外”的范围之外。当前不以主机测试宣称功率级安全，也不把算法模型的结果作为实机调参依据。
